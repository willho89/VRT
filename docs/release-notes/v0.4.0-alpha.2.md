Second alpha of VRT for Meta Quest 2 and Quest 3. **Download `VRT-0.4.0-alpha.2.apk` below**; one APK for both headsets.

**Updating from alpha 1:** install over it (SideQuest or `adb install -r`). Your settings, saves and TV placement are kept.

### New
- **Comfort options** (TV menu → COMFORT, VR room): snap or smooth turning, snap angle, turn speed, walk speed, walk toward where you look or where the controller points, a comfort vignette while moving, and a seated height offset.
- **Your own rooms**: add a VR room as a glTF model plus a small JSON file in `/sdcard/VRT/rooms/`, then choose it under TV menu → ROOM. The CRT lights your model, and you can place the TV on its furniture. Guide: [docs/rooms.md](https://github.com/willho89/VRT/blob/main/docs/rooms.md). Try the example den in [examples/rooms/den](https://github.com/willho89/VRT/tree/main/examples/rooms/den).
- **Real controller models** in the VR room: your headset's own controllers (hidden in AR, where you see the real ones).
- **Widescreen DVDs** (TV menu → WIDE): **ZOOM** (full screen, correct shapes, sides trimmed; the new default), STRETCH, LETTERBOX or PAN&SCAN.

### Improved
- **Audio/video sync**: sound now trails the picture by ~45 ms instead of ~140 ms (games feel more responsive too), with no drift over a 30-minute test.
- **DVD menus**: pointing at buttons now lines up through the TV's overscan and curvature.
- **Quest 2**: lighter rendering defaults (no MSAA, stronger foveation) for more headroom.
- The guide's channels start at 01. Long TV-menu labels no longer run into their values.

### Install (new users)
1. Put the headset in developer mode.
2. Sideload the APK with [SideQuest](https://sidequestvr.com/) or `adb install VRT-0.4.0-alpha.2.apk`.
3. Open VRT from **Unknown sources** and allow **All files access**.
4. Stay online the first time you use each system: emulator cores download from the libretro buildbot.

VRT ships no games or videos. ROMs go in `/sdcard/VRT/roms/<System>/` and DVDs in `/sdcard/VRT/video/`. See the [README](https://github.com/willho89/VRT#readme) for everything else.

### Known issues
- Alpha: settings and formats may still change.
- PAL (50 Hz) video can't pace perfectly evenly: Quest has no 100 Hz mode.
- Signed with a development key, the same as alpha 1, so this one installs over it.
